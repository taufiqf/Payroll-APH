# Payroll Anis Pet House

A mobile-friendly, pastel-blue gothic-kawaii payroll estimate calculator for Anis Pet House Semenyih. The header mascot is an original orange cat illustration wearing a light-blue hoodie and black sunglasses.

## Included
- Permanent staff: basic salary, allowance, ordinary overtime, rest-day work and public-holiday work.
- Part-time staff: prorated pay based on RM70 per 8-hour full day, agreed shift hours, and additional hours.
- Print / Save as PDF.
- Responsive layout for phones and computers.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Open the Pages URL shown by GitHub after deployment.

## Default values
- Permanent staff: RM3,000 basic + RM300 allowance, 8 normal hours/day, 5.5 workdays/week.
- Part-time: RM70 per 8-hour full day.

## Important
This is an estimate tool, not a statutory payroll system or legal advice. Confirm employee coverage, normal working hours, wage components, rest days, public holidays and part-time rules with the Department of Labour / payroll professional before paying wages. The calculator uses simplified assumptions and does not calculate statutory deductions such as EPF, SOCSO, EIS, PCB, unpaid leave or prorated monthly salary.
